# DreamLayer knowledge base

The published reference site for DreamLayer, served from this repo's
`gh-pages` branch at https://letsgettoworkbro.github.io/dreamlayer-docs/

This repo holds only the built site. The book's markdown source and the
tooling that generates every image live in the (private) `dreamlayer`
repository and are deployed here automatically by its `knowledge-base`
workflow. Do not edit these files by hand; they are overwritten on each
deploy.
